Acerca del Sistema

Aplicación web corporativa desarrollada como solución integral para la gestión de datos, utilizando un stack tecnológico moderno: Python Flask, MongoDB Atlas para la persistencia de datos y Render para el despliegue.

Funcionalidades

  • Gestión completa de usuarios (CRUD).
  • Búsqueda dinámica y filtrado por nombre.
  • Validación de datos y manejo de duplicados.
  • Exposición de datos mediante API REST.
  • Estadísticas en tiempo real mediante Dashboard.

Tecnologías

  • Backend: Python 3 con Flask.
  • Base de Datos: MongoDB (PyMongo).
  • Frontend: HTML5, CSS3.
  • Infraestructura: Despliegue en la nube (Render).
